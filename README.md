# За горизонтом

Мобильное веб-приложение: живые камеры гор, моря, леса, северного сияния и космоса во встроенном плеере, с фоновыми звуками природы.

- Один файл `index.html`, без сборки и серверной части.
- Устанавливается на телефон как приложение (PWA).
- Источники: Shymbulak, NPS, USGS, NOAA, NICT, 3Cat и другие — права на материалы принадлежат их владельцам.
